Для того что бы загрузить програму на esp32 надо:
1) скачать расширение для VScode под названием PlatformIO IDE.
2) скачать драйвер CP2102 с сайта Silicon labs
3) Сочетанием "Ctrl + Shift + P" открыть меню, где выбрать "PlatformIO: Open Terminal"
4) соберите сборку данной командой "pio run"
5) исчете порт к которому подключен микроконтроллер "pio device list"
6) перепрошейте плату "pio run -t upload"

Для правельной колибровки энкодера требуется задать 2 константы:
1) STEPS_PER_REVOLUTION - это количество шагов энкодера для прохождения полного оборота
2) WHEEL_CIRCUMFERENCE_MM - это перевод скорости из rmp/s (обороты в секунду) в мм/с. В нее мы вписываем значение полученное в 5 этапе колибровки, коэффициент k_conv домноженное на значение STEPS_PER_REVOLUTION.
