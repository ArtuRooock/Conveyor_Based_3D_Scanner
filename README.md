Calibrate - содержит файлы, необходимые для калибровки камер (включая прогон через тестовые видео)
Encoder - содержит файлы считывания данных с энкодера + файл, который ставит в соотвествие кадрам с камеры значение энкодера
Volume - набор программ, которые считают объем объекта по облаку точек
CloudBuilder - содержит файлы, реализующие логику детекции лазера и построения облака точек
