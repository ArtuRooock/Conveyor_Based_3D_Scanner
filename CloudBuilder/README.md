Camera.py - файл класса Camera, реализующий считывание кадров с камеры и сохранения их в список для последующей обработки.
ComReader.py - файл класса ComReader реализующий чтение данных с микроконтроллера через COM порт в формате json
MotionData.py - Файл класса MotionData, связывющий между собой картинку с камеры и данные с энкодера, которые были зафиксированы на момент съёмки.
LaserDetector.py - файл, содержащий набор функций для распознавания лазера с кадров камеры
CloudBuilder.py - файл класса CloudBuilder со статическими методами, реализующие логику триангуляции и переход между системами координат
CalibrationFiles - директория с .npz файлами калибровки для 2-ух камер
main.py - основной скрипт, считывающий поток данных с 2-ух камер и энкодера и строящий по ним облако точек
